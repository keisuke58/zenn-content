## はじめに

東京駅日本橋口の目の前に2028年完成予定の **TORCH TOWER（常盤橋プロジェクト）** は、高さ390mで完成時に日本一の超高層ビルとなる。総事業費は約1兆円規模、デベロッパーは三菱地所。

不動産投資データを分析している[PropAnalytics](https://real-estate-tracker-web-zeta.vercel.app)では、82件の東京再開発プロジェクトを7指標でスコアリングしているが、**TORCH TOWERのスコアは97/100で全プロジェクト中1位**だ。

この記事では「なぜ97点なのか」を指標ごとに分解し、周辺不動産への波及効果と具体的な投資シミュレーションを数字で示す。

## 投資スコア97点の根拠：7指標を分解する

PropAnalyticsのスコアは以下7指標の重み付き総合評価だ。

| 指標 | TORCH TOWERの評価 | 理由 |
|------|------------------|------|
| **立地スコア** | ★★★★★ | 東京駅徒歩2分・大手町徒歩3分。国内最高クラスの交通利便性 |
| **デベロッパー信頼度** | ★★★★★ | 三菱地所は国内最大手。資金力・竣工実績とも最高評価 |
| **地価トレンド** | ★★★★★ | 大手町・丸の内エリアは過去10年で地価+60%超 |
| **プロジェクト規模** | ★★★★★ | 延床54万㎡・総事業費1兆円。波及効果が極めて大きい |
| **完成フェーズ** | ★★★★☆ | 建設中のため「着工前プレミアム」はやや剥落済み |
| **ハザードリスク** | ★★★★☆ | 大手町は地盤固い。ただし荒川・隅田川の浸水リスクは存在 |
| **市場流動性** | ★★★★★ | 国際投資家・法人需要が厚く出口に困らない |

**1点のロスは「完成フェーズ」と「浸水リスク」のわずかな減点のみ。** 純粋な立地・デベロッパー・規模のポテンシャルでは満点評価だ。

## 具体的な投資シミュレーション

大手町駅徒歩5分圏内の新築1LDK（45m²）を想定したシミュレーション。

### ケース①：実需向け1LDK（フルローン・35年）

| 項目 | 金額 |
|------|------|
| 購入価格 | 1億2,000万円 |
| 坪単価換算 | 約267万円/m² |
| 想定家賃 | 35万円/月 |
| **表面利回り** | **3.5%** |
| 管理費・修繕積立 | 3万円/月 |
| 空室率想定 | 3% |
| **実質利回り** | **3.0%** |
| ローン返済（変動0.5%） | 30.9万円/月 |
| **月次キャッシュフロー** | **+1.1万円** |

表面利回り3.5%は都心超一等地としては標準的。ただし出口（売却）時の値上がり益（キャピタルゲイン）込みで評価する必要がある。

### ケース②：10年保有・売却のIRR計算

| 項目 | 前提 |
|------|------|
| 購入価格 | 1億2,000万円 |
| 自己資金 | 3,600万円（30%） |
| 年間CF | +13万円/年 |
| 10年後売却価格 | 1億4,400万円（+20%想定） |
| **IRR（内部収益率）** | **約7.8%** |

地価上昇を年2%で保守的に見積もっても IRR 7.8%。 **インデックス投資（年5〜7%）を上回る水準**だ。

## ハザードリスク評価

投資判断で見落とされがちなのがハザードリスクだ。大手町エリアは以下のリスクがある。

| リスク項目 | 評価 | 詳細 |
|-----------|------|------|
| 地盤 | **良好** | 台地・洪積層。液状化リスク低 |
| 液状化 | **低** | 東京都ハザードマップ：ランクC（低リスク） |
| 浸水（内水） | **中** | 集中豪雨時の内水氾濫リスクあり（浸水深0〜0.5m想定） |
| 浸水（外水） | **中** | 荒川・隅田川決壊時は0.5〜3m浸水の可能性（100年確率） |
| 震度6弱30年確率 | **47%** | 首都圏平均並み |
| **総合グレード** | **B** | 立地優秀・浸水リスクのみ要注意 |

浸水リスクは保険料の上昇と出口（売却）時の査定に影響する。ただし大手町は超高層ビルが多く、建物自体の浸水対策（免震・止水板）が充実している点は評価できる。

## 投資判断：今買うべきか？

### 着工前・建設中フェーズの優位性

再開発プロジェクトの地価波及は以下の3フェーズで起きる：

```
計画発表 → 着工 → 竣工
  ↑           ↑       ↑
価格低め   価格上昇   価格高止まり
（買い場）  （上昇中）  （すでに織り込み済み）
```

TORCH TOWERは現在「建設中」フェーズ。**計画発表直後の最安値は過ぎているが、竣工後の価格よりは低い。** 2028年竣工に向けてさらなる上昇余地がある。

### 結論

| 投資スタイル | 判断 |
|------------|------|
| キャピタルゲイン狙い（5〜10年保有） | **◎ 積極的に検討** |
| インカムゲイン狙い（CF重視） | **△ 利回り3%台は低め** |
| REIT・小口投資 | **◎ 大手町REITで間接参加も有効** |

単純な表面利回りだけで見ると3〜3.5%台と高くない。しかし「東京駅徒歩2分・三菱地所・完成時日本一」という希少性と地価上昇のキャピタルゲインを加味すると、長期保有前提では有力な選択肢だ。
