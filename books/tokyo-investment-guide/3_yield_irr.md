## 「表面利回り5%」に騙されるな

不動産情報サイトに掲載される「利回り」はほぼ全て**表面利回り**だ。

```
表面利回り = 年間賃料収入 ÷ 購入価格 × 100
```

例：購入価格5,000万円、月10万円の家賃 → 表面利回り = 240万 ÷ 5,000万 = **4.8%**

しかしこれは「コストゼロ・空室ゼロ」の理想値。実際には：

| コスト項目 | 年間コスト（例） |
|-----------|--------------|
| 管理委託費（賃料の5%) | 12万円 |
| 修繕積立金 | 12万円 |
| 管理費 | 18万円 |
| 固定資産税 | 8万円 |
| 空室損失（空室率5%） | 12万円 |
| 火災保険・雑費 | 5万円 |
| **合計コスト** | **67万円/年** |

```
実質利回り = (年間賃料 - 年間コスト) ÷ 購入価格 × 100
           = (240万 - 67万) ÷ 5,000万 × 100
           = 3.46%
```

表面4.8% → 実質3.5%。**1.3ポイントの差**が出る。

## ローンを使った場合のキャッシュフロー

自己資金1,500万円（30%）、残り3,500万円をローン（変動金利0.5%・35年）の場合：

```
月次キャッシュフロー計算：
  賃料収入：    +100,000円
  ローン返済：  -90,600円（元利均等）
  管理費等：    -5,600円（月割り）
  ────────────────────
  月次CF：       +3,800円/月
  年次CF：       +45,600円
```

このケースでは**自己資金1,500万円に対してCFは年4.6万円**。COC（自己資金利回り）はわずか0.3%。

ローンを使うとCFは薄くなる。ここで問うべきは「毎月いくら手残りがあるか」ではなく「**10年後に売ったとき総合リターンはいくらか**」だ。

## IRR（内部収益率）で10年間の総合収益を評価する

IRRは「全キャッシュフローの現在価値がゼロになる割引率」だ。投資全体のリターンを1つの数字で表せる。

### IRR計算の前提を設定する

| 項目 | 前提値 |
|------|--------|
| 購入価格 | 5,000万円 |
| 自己資金 | 1,500万円（30%） |
| 借入金額 | 3,500万円 |
| 金利 | 0.5%（変動） |
| 年間CF | +45,600円 |
| 保有期間 | 10年 |
| 10年後売却価格 | 5,500万円（+10%上昇想定） |
| 売却コスト | 200万円（仲介手数料等） |

### CFの時系列

| 年 | キャッシュフロー |
|----|--------------| 
| 0年目 | -1,500万円（自己資金） |
| 1〜10年目 | +4.6万円/年 |
| 10年目（売却） | +5,500万 - 3,200万（残債） - 200万（コスト） = +2,100万円 |

```
IRR ≈ 7.8%
```

年7.8%のリターンは **インデックス投資（S&P500の年平均7〜10%）** に近い水準。しかしレバレッジ（ローン）を使っているため、自己資金ベースでの実効利回りとして捉えるべきだ。

## 実質利回り・COC・IRRの使い分け

| 指標 | 用途 | 目安 |
|------|------|------|
| 表面利回り | 物件の粗い比較 | 参考程度 |
| 実質利回り | 運営コスト込みの収益性 | 4%以上が目安 |
| COC（自己資金利回り） | 毎月のCF感覚 | 3%以上あると安心 |
| IRR | 10年以上の総合評価 | 5%以上が目安 |
