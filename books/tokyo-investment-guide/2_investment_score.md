## スコアは「買い推奨」ではなく「ポテンシャル評価」

PropAnalyticsの投資スコアは0〜100点の総合評価だが、「スコアが高い＝今すぐ買い」ではない。

**スコアが測るもの：**
- 立地の優位性
- デベロッパーの信頼性と実績
- 地価の中長期上昇余地
- プロジェクトの規模と波及効果
- ハザードリスクの低さ
- 市場での売買しやすさ

**スコアが測らないもの：**
- 現在の割安・割高感（価格水準）
- 個別物件の管理状態
- 金利動向・ローン条件

スコアは「**この場所の不動産は長期的に価値が上がりやすいか**」を評価しているものだと理解してほしい。

## 7指標の詳細

### 1. 立地スコア（重み25%）

評価軸：
- 主要駅からの徒歩分数
- 複数路線・複数駅へのアクセス
- 生活利便施設（スーパー・病院・学校）
- 繁華性・商業集積度

| 徒歩分数 | スコアへの影響 |
|--------|-------------|
| 1〜3分 | +25点 |
| 4〜7分 | +20点 |
| 8〜12分 | +15点 |
| 13〜20分 | +8点 |

東京駅・渋谷・新宿・品川の主要4ターミナルへのアクセスが良いほど追加加点。

### 2. デベロッパー信頼度（重み20%）

過去の再開発実績・財務安定性・竣工遅延リスクで評価。

| デベロッパー | 評価 |
|------------|------|
| 森ビル・三菱地所・三井不動産 | ★★★★★ |
| 住友不動産・東急・野村不動産 | ★★★★☆ |
| 大京・東京建物 | ★★★☆☆ |
| 中小デベロッパー | ★★☆☆☆ |

### 3. 地価トレンド（重み20%）

エリアの過去5年・10年の地価推移と将来予測。

公示地価データ（国土交通省）をベースに：
- 過去5年の年平均上昇率
- 周辺の再開発余剰（容積率未消化）
- インバウンド需要・国際化指数

### 4〜7. その他指標

| 指標 | 重み | 主な評価軸 |
|------|------|---------|
| プロジェクト規模 | 15% | 延床面積・総事業費・波及半径 |
| 完成フェーズ | 10% | 計画中 > 建設中 > 完成済 |
| ハザードリスク | 5% | 浸水・液状化・震度確率 |
| 市場流動性 | 5% | 売買件数・外国人投資家比率 |

## スコア別の投資戦略

```
90〜100点：プレミアムエリア
  → キャピタルゲイン狙い。利回りは低いが値上がり期待大
  → 例：TORCH TOWER周辺・麻布台ヒルズ周辺

80〜89点：有望エリア
  → CF + キャピタルゲインのバランス型
  → 例：渋谷再開発周辺・内幸町周辺

70〜79点：標準エリア
  → 利回り重視ならここ。値上がりは限定的
  → 例：中規模再開発周辺

70点未満：慎重判断エリア
  → ハザードリスクや流動性に懸念あり
  → 余程の割安感がなければパス
```

## 実際のスクリーニング手順

[PropAnalyticsのランキング](https://real-estate-tracker-web-zeta.vercel.app/ranking)を使った絞り込み：

1. スコア80点以上でフィルタリング（有望候補：約20〜25件）
2. ステータス「建設中」「計画中」をさらに絞る（竣工前のアップサイドを取る）
3. 坪単価と自己資金を照合して購入可能物件を特定
4. 次チャプターの利回り計算で収益性を検証

> スコア・ステータスのフィルタリングは [PropAnalytics](https://real-estate-tracker-web-zeta.vercel.app/projects) で無料でできる。
