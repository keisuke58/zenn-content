## スコアは「ポテンシャル評価」であり「買い推奨」ではない

PropAnalyticsの投資スコア（0〜100点）は、物件の長期的な価値上昇ポテンシャルを評価する指標だ。重要なのは**「スコアが高い＝今すぐ買うべき」ではない**という点だ。

スコアが測るもの：

- 立地の長期的な優位性
- デベロッパーの実行力と信頼性
- エリアの地価上昇トレンドの持続性
- プロジェクトの周辺への波及効果
- ハザードリスクの低さ

スコアが測らないもの：

- 現在の価格水準の割安・割高感
- 個別物件の管理状態・築年数
- 金利動向・ローン審査通過可能性

「立地が良くデベロッパーが信頼できる」が97点であっても、現在の価格が高すぎれば投資リターンは悪化する。スコアはスクリーニングの第一段階として使い、最終判断は次チャプターの利回り・IRR計算で行う。

## 7指標の詳細解説

### 指標1：立地スコア（重み 25%）

最も重みが大きい指標。評価軸は4つ：

**駅距離：**

| 徒歩分数 | 加点 |
|--------|------|
| 1〜3分 | 25点 |
| 4〜7分 | 20点 |
| 8〜12分 | 15点 |
| 13〜20分 | 8点 |
| 20分超 | 0〜3点 |

**ターミナル駅へのアクセス加点：** 東京・渋谷・新宿・品川への乗換なし直通、または1回乗換30分以内であれば追加加点。TORCH TOWER（東京駅直結）は最高加点。

**複数路線の利用可能性：** 2路線以上使えると、1路線遅延時のリスクヘッジになる。麻布台ヒルズは神谷町・六本木一丁目の2駅が徒歩圏内で高評価。

### 指標2：デベロッパー信頼度（重み 20%）

デベロッパーの評価は「過去の竣工実績・財務安定性・設計品質」の3軸で行う。

| デベロッパー | 代表実績 | 評価点 |
|------------|--------|------|
| 森ビル | 六本木ヒルズ・麻布台ヒルズ | 98 |
| 三菱地所 | 丸の内・常盤橋 | 96 |
| 三井不動産 | 日本橋・内幸町 | 95 |
| 東急不動産 | 渋谷スクランブルスクエア | 90 |
| 野村不動産 | プラウドシリーズ | 85 |
| 住友不動産 | 新宿・汐留 | 83 |

財務安定性は実際に竣工遅延リスクに直結する。大手デベロッパーの再開発は計画から竣工まで10年以上かかることもあり、その間に財務悪化が起きると計画変更・中止リスクがある。

### 指標3：地価トレンド（重み 20%）

国土交通省の公示地価データ（毎年3月発表）をベースに、エリアの5年・10年トレンドを評価する。

東京都心5区（千代田・中央・港・新宿・渋谷）の2020〜2024年地価推移：

| 区 | 2020年比 | 年平均上昇率 |
|---|--------|-----------|
| 港区（商業） | +42% | +7.3%/年 |
| 千代田区 | +38% | +6.7%/年 |
| 渋谷区 | +35% | +6.2%/年 |
| 中央区 | +31% | +5.5%/年 |
| 新宿区 | +28% | +5.1%/年 |

さらに「容積率未消化」の多いエリアは上昇余地が大きい。再開発が入ると容積率が緩和・消化され、土地利用効率が上がるため地価が押し上げられる。

### 指標4：プロジェクト規模（重み 15%）

総事業費と延床面積で評価する。単独ビルより「街区全体の再生」を伴うプロジェクトほど周辺への波及効果が大きい。

| 規模 | 総事業費 | スコアへの影響 |
|-----|--------|------------|
| 超大規模 | 3,000億円超 | +15点 |
| 大規模 | 1,000〜3,000億円 | +10点 |
| 中規模 | 300〜1,000億円 | +7点 |
| 小規模 | 300億円未満 | +3点 |

### 指標5：完成フェーズ（重み 10%）

アップサイドの大きさは「完成まで何年あるか」に比例する。

```text
計画中（未着工）  → 最もアップサイド大きいが不確実性も高い
建設中（着工済）  → アップサイドあり、実現確度は高い  ← 今のTORCH TOWER
竣工済           → アップサイドは価格に織り込み済
```

**「建設中」フェーズが最も投資妙味が高い**。計画が確定し不確実性が消えた一方、まだ価格に完全には反映されていない。

### 指標6・7：ハザードリスク・市場流動性（各 5%）

ハザードリスクは国土交通省のハザードマップポータルのデータを使用。浸水・液状化・震度確率の3要素を加重評価。港区・千代田区などの台地上エリアは低リスクで高評価。

市場流動性は「1年間の売買件数 ÷ 総戸数」で計算した回転率に外国人投資家需要を加味。都心3区（千代田・中央・港）はREITや外国人法人も買主になるため流動性が高い。

## スコア別の投資戦略

スコアと戦略のマッピング：

| スコア帯 | エリア例 | 推奨戦略 |
|--------|--------|--------|
| 90〜100 | TORCH TOWER周辺・麻布台周辺 | キャピタルゲイン狙い。CF<0でも可 |
| 80〜89 | 渋谷駅直近・内幸町周辺 | CF + キャピタルゲインのバランス型 |
| 70〜79 | 中規模再開発周辺 | インカムゲイン重視。CF黒字が必須条件 |
| 70未満 | ハザード懸念・流動性低エリア | 余程の割安感がなければ見送り |

90点超のプレミアムエリアは「今はCFがマイナスでも10年後の売却益で全体を黒字にできる」という確信がある場合のみ投資を検討する。CF+IRR両方で判断することが鉄則だ。

## 実際のスクリーニング手順

[PropAnalyticsのランキング](https://real-estate-tracker-web-zeta.vercel.app/ranking)を使った絞り込みフロー：

1. スコア80点以上でフィルタ → 約20〜25件に絞り込む
2. ステータス「建設中」「計画中」でさらに絞る → 約10〜15件
3. エリア（通勤圏・知っている街）で絞る → 3〜5件
4. 次チャプターの利回り計算で収益性を数値で検証

このステップで「感情で買う」から「データで買う」に変わる。
